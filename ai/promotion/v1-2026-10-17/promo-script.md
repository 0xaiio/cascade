# cascade 宣传视频文稿

本文件是宣传视频**唯一权威脚本**：旁白、字幕、画面与操作全部以本文件为准。配套成片为
[`cascade-promo.mp4`](cascade-promo.mp4)，字幕文件为 [`cascade-promo.srt`](cascade-promo.srt)，
生成与复现方式见 [README.md](README.md)。

- 语言：简体中文
- 旁白：男声，专业新闻播报音色（沉稳有力），恒定语速
- 字幕：与旁白逐句同步，句子边界取自 TTS 的词级时间戳（不是估算）
- 画面：真实环境录屏（终端 + 真实运行的 cascade 界面），非示意图
- 时长：约 6 分半（落在要求的 3–10 分钟区间内）

> 已发布：B站 [BV1JQJY6LExf](https://www.bilibili.com/video/BV1JQJY6LExf)，分区「科技 · 计算机技术」，
> 标签 `youtube` / `yt-dlp` / `bilibili`，自制，归入合集 `0xaiio`。投稿参数与记录见 [README.md](README.md#发布记录)。

## 4. 逐镜脚本

> 每镜的「字幕」就是旁白文本的换行切分。TTS 按整段合成，字幕时间轴按词级时间戳回填，
> 因此字幕起止与音频严格对齐，不存在手工估时。

### S0 片头

- **画面**：深色标题卡，居中显示 `cascade`、副标题「YouTube 下载控制台」、仓库地址；淡入淡出。
- **字幕 / 旁白**：

```
在本地，把 YouTube 视频下载，
做成一条可控、可观察的流水线。
这里是 cascade，一个跑在你自己电脑上的下载控制台。
```

### S1 项目定位

- **画面**：真实首页全景，缓慢推近；顶部状态条可见。
- **字幕 / 旁白**：

```
cascade 是一个本机、单用户的 YouTube 下载控制台。
它把链接解析、清晰度与字幕选择、下载队列和任务状态，
收进一个网页界面；后端用 yt-dlp 真正完成下载。
```

### S2 目标用户与边界

- **画面**：浏览器打开真实仓库页面（`github.com/0xaiio/cascade`），缓慢滚动 README。
- **字幕 / 旁白**：

```
它面向三类人。
需要把公开视频稳定存档下来的普通用户；
需要批量处理合集、并且要求每一步失败原因都能看见的重度使用者；
以及想读一份结构清晰、文档与测试齐备的工程实现的开发者。
它不绕过任何权限限制，也不面向公网部署。
```

### S3 克隆仓库

- **画面**：终端录屏。提示符逐个字符敲出 `git clone git@github.com:0xaiio/cascade.git`（SSH），
  回车后是真实的克隆输出；克隆完成后 `cd cascade` 并 `ls` 出真实目录结构。
- **字幕 / 旁白**：

```
从零开始，只有一步。
打开终端，克隆仓库。
项目同时托管在两个 GitHub 仓库，
开发以 0xaiio 下的 cascade 为主。
```

### S4 一键启动

- **画面**：终端录屏。敲出 `init\start.ps1`，真实执行「安装依赖 → 构建前端 → 启动后端」，
  最后打印服务地址。
- **字幕 / 旁白**：

```
进入目录，运行对应平台的一键启动脚本。
它会依次做三件事：安装后端依赖、构建前端、启动服务。
默认单端口模式：后端在同一个端口上同时提供页面和接口。
默认端口被占用时，它会自动顺延到一个空闲端口，
并把实际监听地址打印出来。
```

### S5 打开首页

- **画面**：浏览器打开服务地址；画面停在首页，状态条与两个主区域可见。
- **字幕 / 旁白**：

```
启动完成后，脚本会自动打开浏览器。
这就是 cascade 的首页。
左侧是解析链接和任务中心，右侧是下载选项和设置。
顶部状态条先回答一个问题：这台机器能不能干活。
它显示 ffmpeg 是否可用，以及 cookies 的状态。
```

### S6 解析链接

- **画面**：向输入框粘贴真实视频链接 → 点击解析 → 出现标题、时长、封面与格式列表。
- **字幕 / 旁白**：

```
第一步是解析。
把视频或播放列表链接粘进来，点击解析。
后端会取回标题、时长、封面和全部可用格式。
如果是播放列表，这里会展开成条目列表，
你可以只勾选需要的那几条。
```

### S7 下载选项

- **画面**：依次指向下载模式、清晰度、字幕语言、字幕来源与格式、四个开关。
- **字幕 / 旁白**：

```
接下来是下载选项。
下载模式支持视频加字幕、仅视频、仅字幕三种。
清晰度只需要选一个目标值，默认 1440p；
具体格式由后端按源视频实际可用的流自动挑选。
源视频达不到你要的清晰度时，
界面会说明降级到了哪一档、以及为什么。
字幕可以选择语言、来源和格式；
人工字幕与自动字幕缺一类时，会自动回退到另一类，并如实标注来源。
下面还有保存元数据、保存缩略图、跳过已下载、完成后通知这几个开关。
```

### S8 加入队列与任务中心

- **画面**：点击「加入下载队列」→ 任务行出现 → 进度、速度、大小、剩余时间滚动 →
  完成后指向播放、打开文件夹、复制链接等操作按钮。
- **字幕 / 旁白**：

```
确认后点击加入下载队列。
任务中心通过服务端事件流实时刷新，
进度、速度、文件大小、预计剩余时间，
以及预检得到的实际分辨率和格式，都不需要手动刷新。
任务行上可以暂停、重启，也可以只删任务，或者连文件一起删。
下载完成的视频可以直接播放，或者打开所在文件夹。
如果某个视频卡住，后端会在九十秒内主动判定为停滞失败，
而不是让你无限等待。
```

### S9 设置与运行环境

- **画面**：设置面板：并发、限速、重试次数 → 下方运行环境的自检结论。
- **字幕 / 旁白**：

```
设置面板管的是全局行为。
并发是同时下载几个视频，默认五个；网络不稳时建议调成一。
限速和重试次数改完立即生效：
正在下载的视频会取消当前任务，用断点续传的方式重新入队。
下面的运行环境区块回答：这台机器到底能不能干活。
比如解析 YouTube 的加密参数需要 JavaScript 运行时，
这里会直接给出可用状态和原始报错；
补装之后点重新自检即可，不必重启应用。
```

### S10 代理与 cookies

- **画面**：代理输入框旁的「常用端口」浮层 → 点击「检测代理」→ 结果；
  切到 cookies 区，指向三种获取方式与校验结论。
- **字幕 / 旁白**：

```
网络和登录是这类工具最容易出错的地方，
cascade 把它们做成可验证的。
代理留空表示自动跟随系统，也可以强制直连。
点检测代理，它会真的发一次请求，
把状态码、耗时和收到的字节数原样给出，而不是只报一句失败。
cookies 同理：文件存在不等于能用。
校验会先做离线体检，再带上这份 cookies 真的访问一次 YouTube，
给出未配置、登录态无效或登录态有效这三档结论，并附上证据。
```

### S11 辅助说明

- **画面**：悬停某个说明胶囊 → 浮层出现；点击固定展开；指出「不抢焦点」。
- **字幕 / 旁白**：

```
界面上所有解释性内容都不平铺在页面上，
而是收在对应功能区旁边的说明胶囊里。
鼠标悬停即可预览，点击固定展开。
打开时不会抢走输入焦点，也不会挡住其他操作。
```

### S12 B站 投稿

- **画面**：设置面板底部的「B站 上传」体检区 → 任务行上的上传按钮 → 单视频预填表单 →
  合集模板表单与实时预览表。
- **字幕 / 旁白**：

```
下载完成的视频，还可以直接投稿到哔哩哔哩。
这是一条完全独立的链路：独立账号、独立登录文件、独立队列。
开始之前先做一次体检，缺什么会明确告诉你下一步。
单个视频走一张预填好的表单：
标题、分区、标签、简介都已经填好。
自制还是转载、要不要归集，都可以在这里改。
计数上限来自服务端，超限会明确报错，不会静默截断。
整个合集则走模板批量投稿，
标题和简介里可以用占位符，预览表会当场算出每一条要提交的内容。
投稿完成后，应用会回读账号稿件列表对账，
只有真正对上了，才显示已上传。
```

### S13 片尾

- **画面**：标题卡，仓库地址居中，附一句权利提示。
- **字幕 / 旁白**：

```
cascade。仓库地址在屏幕上。
请只下载你有权利获取的内容。
感谢观看。
```

## 6. 口径与边界

- 片中演示的是**真实运行**的 cascade：真实克隆、真实启动、真实解析、真实下载。
  未做任何「界面假数据」处理；下载时长由演示所用源视频决定。
- 界面文案、字段上限等以演示当日 `main` 分支的实现为准。
- 旁白提到的时间数字（如「九十秒停滞」）取自实现中的默认阈值
  （`YTDL_STALL_TIMEOUT_SECONDS`），非宣传口径的概数。
- 视频不承诺下载稳定性：账号态、地区、会员或 PO token 强制场景仍可能失败，
  这也是项目自身在需求文档里写明的边界。
