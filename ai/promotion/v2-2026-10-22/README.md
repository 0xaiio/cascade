## 制作方式

1. **旁白**：`edge-tts` 逐镜合成，取 `WordBoundary` 词级时间戳把字幕行对齐到音节边界；
   35 行字幕全部按时间戳通过（没有一条走「按字数比例」的退化路径）。
2. **界面**：CDP 无头 Edge 驱动真实页面，`Page.startScreencast` 截帧 → 按帧时间轴编码成
   H.264；光标是注入的 DOM 覆盖层（真实点击仍然经 CDP `Input.dispatchMouseEvent`）。
3. **卡片**：同一套 CDP 渲染 HTML 后截图（片头 / 字幕文件 / 片尾）。
4. **总装**：`ffmpeg` 拼接 + 烧字幕 + 旁白与低电平音床混音 → `loudnorm` 归一。

脚本落在 `tmp_acceptance/promo2/`（不进版本库）：`scenes.py`（旁白唯一源）、
`make_narration.py`、`record_browser.py`、`build_frames.py`、`build_video.py`。

## 保真度说明（重要）

原则与上一支一致：**界面内容全部来自真实运行**，只在「时序」上做工程处理。

| 处理 | 为什么 | 界面上还能不能当真 |
| --- | --- | --- |
| 解析响应由 CDP `Fetch` 拦截固定到达时刻，响应体是同一后端抓下的真实 JSON（S4） | yt-dlp 解析耗时实测 5–15 s 波动，直录无法与旁白对齐 | 解析结果（标题、4:47、8 个格式、自动字幕）全部真实 |
| S5 前段剪掉 10 秒（跳剪，不加速） | 真实 144p 下载用了约 17 秒，而旁白第 3 行就要说「跑完的瞬间」 | 下载、进度、完成提醒都是真实事件，只剪掉了等待 |
| 提示音在后期按同一合成参数补入 | 浏览器截帧不含系统音频；声音由前端 Web Audio 现场合成（C6 + G6，指数包络），代码里没有音频文件 | 波形与产品一致，见 `frontend/src/notifications/notifications.ts` |
| S6 只演示「字幕」按钮，不点开系统「打开方式」窗口 | 那是原生窗口，不在浏览器采集范围内 | 按钮可用性来自后端算出的真实 `subtitle_path`；文件内容是 S6B 里真实 `.vtt` 的前 4 条 cue（已略过 10 毫秒过渡条与 cue 设置） |
| S11 点「已上传」后，把录制目标提到前台并在同一标签页打开同一稿件地址 | 真实行为是新标签页；后台标签不产生截屏帧 | 打开的页面是真实稿件页（Ep 137 → `BV1hinC6FEVh`） |
| 演示素材为公开视频《C++ Weekly - Ep 25》（4:47，仅 144p 下载，用于演示提醒与字幕） | 需要一个「小而带字幕」的真实任务 | 下载、字幕、完成提醒都是真实发生的；该任务已从任务库删除 |

**没有做的事**：没有为了让画面好看而伪造任何状态、没有用「假数据」替换任一界面字段、
没有重投任何视频（本片全程没有新的 B站 投稿产生）。

## 发布记录

- 投稿走项目自身的模块：`bili_bin`（biliup 上传）→ `bili_api.find_archive`（对账拿 aid/bvid）
  → `fetch_video`（拿 cid）→ `find_season_section`（合集 id → 分区 id）→ `add_episodes`。
- **本次是 013 修好之后的第一次真实归集**：`season=9343273 → section=10455347`，一次成功，
  没有出现 `-404 啥都木有`。归集后该分区 `epCount` 从 1 变成 2。
- 置顶评论同样走项目自身的 `send_and_top_comment`（幂等）。**首次置顶仍返回过一次
  `-404 啥都木有`，15 秒后重跑同一条即成功** —— 新评论尚未被置顶接口索引时也是这个码，
  与 [013 §未覆盖](../../bug-fix/013-season-section-id-confusion.md) 记的现象一致。
- 稿件投出后约 45 秒 `fetch_video` 才拿得到 `cid`（平台侧延迟），与上一支的观察一致。

## 后续制作注意

- 旁白改 `scenes.py` 后要重跑 `make_narration.py` → 重录受影响的镜 → `build_video.py`；
  只改旁白不重录画面会让「字幕行起点」与画面动作错位。
- 录制 S5 这类「等真实事件」的镜，`wait_for` 的返回值是**调用后**的秒数，不是场景时间；
  要对位提示音请以帧时间轴为准（本次：素材里浮层出现在 17.4 s，剪掉前 10 s 后落在 7.4 s）。
- 后台标签不产生截屏帧：任何 `window.open` 之后必须 `Page.bringToFront` 再继续录。
