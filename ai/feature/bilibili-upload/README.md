## 一句话结论

单视频与视频合集各自加一个「B站图标 + 上传」按钮：单视频点击后弹表单（预填、可改、确认后上传），
合集点击后按模板批量生成元数据、**逐个投稿为独立稿件**。两张表单里都有**归集方式**（新建合集 /
加入已有合集 / 不归集）—— 合集默认「新建」（改动前的行为），单视频默认「不归集」（改动前单视频
从不进任何合集）；选了归集就在全部投稿成功后归集进去。
上传成功的对象，其 B站 图标状态变为「已上传」。

## 技术底座（不在本仓库，是外部依赖）

- 投稿：`biliup-rs 0.2.4`（`biliup.exe`），cookie 文件登录，`upload` 子命令。
- 登录：`passport.bilibili.com` 扫码接口，自建轮询（不用 `biliup login`，它要求交互终端）。
- 合集归集 / 稿件对账 / 封面 / 置顶评论：`member.bilibili.com` 与 `api.bilibili.com` 的非公开接口，自研客户端。

这一套与 WorkBuddy 的 arXiv-daily 自动任务里已验证可用的方案同源（见 `01-requirements.md` 的「技术事实」一节）。

## 边界一句话

这是**本机单用户**功能，不是公网服务；cookie 等同账号密码，绝不入库；B站 侧「合集」需人工审核，
因此本功能能承诺的终态是「稿件已全部提交」，**不承诺「已发布」**。
