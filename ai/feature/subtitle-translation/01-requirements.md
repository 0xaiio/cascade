# 需求：非中文字幕转中文字幕

来源：用户的原始需求与 [plan.md](../../plan/plan.md) 的 2026-11-17 章节；对外落点为
`docs/requirements.md` 的 FR-46 ~ FR-50。

## 必须

1. 导入**已下载的非中文** SRT/VTT，翻译为简体中文。
2. 译文与原字幕**逐条对齐**：条数相同、序号一一对应、时间逐值相等；不拆条、不合条、不重算时间。
3. 原字幕**保留供对照**，源文件不被改写；同时产出纯中文轨和原上译下的对照文件。
4. 翻译进度与结果可预览；失败可重试；人工修订不被重跑覆盖。
5. 导出能被 B站 接受：中文字幕用白名单 `zh`（不是 `zh-CN`），BCC 时间单位是秒。
6. 作为**可关闭的 CC 字幕**挂在稿件上；`zh` 与原 `en` 轨并存，不烧录、不重投视频。
7. 只支持本机模型；外部地址拒绝；运行时不新增依赖。

## 不做（首期）

- 不翻译音频、不生成硬字幕；不自动翻译整个任务列表；不支持繁体目标与双向互译；
- 不提供 API Key 输入框、不调外部服务；
- 不在投稿时静默补译轨 —— 上传是一次明确的用户动作。

## 需求文字与平台事实的冲突

中文语言标识在 B站 是 `zh`，不是需求举例里的 `zh-CN`（后者实测 `79011 不合法的语言`）。
这与上一轮字幕上传的结论一致，见 `docs/technical.md` 的 CC 字幕一节。
